Профили/Варианты редактора

Редактор профиля: три варианта

Во всех вариантах одни и те же поля профиля, один и тот же раздел «Хранение» с исправленным текстом и схемой «что останется». Различается только устройство экрана.

Список профилей

A. Полная страница Рекомендую

Редактор на отдельной странице. Слева разделы с отметкой «включено» и итогом, посередине сворачиваемые разделы, справа живая сводка и команды.

Плюсы
  • Сразу видно, что включено: у каждого раздела точка и итог в одну строку.
  • Свёрнутый раздел сам себя описывает: «Хранение: последние 3 · по дням 5».
  • Есть место для пояснений и схемы «что останется».
  • Сводка и команды всегда на виду, не нужно открывать предпросмотр отдельно.
  • Адрес раздела можно отправить коллеге: #sec-retention.
Минусы
  • Самый большой объём новой вёрстки: страница, роут, три колонки.
  • На узком экране сводка уходит вниз и перестаёт быть «живой».
  • Для первого профиля избыточно: десять разделов сразу.

B. Диалог по-новому

Остаётся диалог по центру. Сверху обязательное, ниже возможности со строкой-итогом и переключателем, «Дополнительно» свёрнуто.

Плюсы
  • Самый дешёвый путь: тот же диалог и тот же роут, меняется содержимое.
  • Переключатель в каждой строке прямо отвечает на вопрос «включено или нет».
  • Для нового профиля достаточно трёх полей, остальное свёрнуто.
Минусы
  • Раздел «Хранение» с пояснениями и схемой тесен в диалоге: нужна прокрутка внутри прокрутки.
  • Команды restic спрятаны за кнопкой, их не видно при правке.
  • Диалог нельзя открыть по ссылке и нельзя оставить на время: закрыл — потерял.
  • Диалог с десятью возможностями снова становится длинным.
Открыть макет B

C. Страница профиля и мастер

Профиль читается как страница из карточек простым языком. «Изменить» открывает малый редактор одного раздела. Создание идёт по трём шагам.

Плюсы
  • Лучше всего для тех, кто не знает restic: текст вместо полей.
  • Мастер даёт готовые наборы хранения, ошибиться труднее.
  • Просмотр профиля нужен всё равно: имя в списке должно куда-то вести.
  • Каждый малый редактор маленький и понятный.
Минусы
  • Две новые поверхности вместо одной: страница чтения и мастер.
  • Править несколько разделов — значит открывать несколько диалогов и сохранять каждый.
  • Общей картины «всё вместе» в момент правки нет, как у A.
  • Опытному администратору медленнее.

Рекомендация: A для правки, мастер из C для создания

Жалоба владельца состоит из двух частей: «непонятно, что включено» и «непонятно, как это работает». Вариант A отвечает на обе в одном экране: точка и итог показывают состояние, раздел раскрывается с пояснением, а справа видно итоговые команды. Ему же проще всего дать ссылку из списка: имя профиля ведёт на страницу.

Мастер из C стоит добавить вторым шагом, только для создания: он убирает десять разделов с первого экрана. Страницу чтения из C отдельно делать не нужно: свёрнутый вариант A уже работает как чтение.

B оставьте как запасной вариант, если нужно выпустить быстро: он правит жалобу частично, а раздел «Хранение» в диалоге остаётся тесным.
