ResticHub / Design principles

Design principles

A clean, restrained administration console. Every value lives in one stylesheet as a custom property. Switch the theme in the top bar to see the dark values.

In one sentence

A white or near-white canvas, neutral greys, 1px borders instead of shadows, one green accent for the main action of a view, blue for links and focus, and semantic colors in muted fills with strong borders. Shadows appear only on overlays. The console stays calm and dense; it never shouts.

Motion

  • 80 to 150ms, ease out. Color, border and background only.
  • No bounce, no elastic, no layout animation.
  • A spinner turns at 700ms, an indeterminate bar sweeps at 1300ms.
  • Reduced motion disables the loops and shortens every transition.

Density

  • Top bar 56px. Tab row 44px. Control height 32px. Table cell padding 12px.
  • A box row carries one line of name and one line of secondary text.
  • Content column is at most 1280px wide; a detail page adds a 300px metadata column.
  • Row hover gives a light tint, never a move or a scale.

Content rules

Case
Sentence case for titles, labels and buttons. Only the product name and proper names keep capitals.
Labels
Short and concrete: "Create host", "Run job", "Revoke". One verb, one action.
Time
A relative time in the row ("3 minutes ago"), the exact time in the title attribute and in the metadata column.
Identifiers
Snapshot IDs, hashes, paths and host names use the monospace face and never wrap in the middle.
Numbers
Tabular figures in tables, counters and statistics. Short units: "1.4 GB", "3m 12s".
Voice
Active, plain, never apologetic. An error says what happened and how to correct it.

Accessibility

Contrast
Text meets WCAG AA (4.5:1 for body, 3:1 for large text and for a control border).
Focus
A visible 2px outline with an offset on every focusable element. Never remove it.
Target
Every control is at least 32px high. An icon-only button is 32 by 32.
Keyboard
Tabs move with the arrow keys. A menu closes on Escape. A dialog traps focus and returns it.
Semantics
Native elements first: button, dialog, table. Roles and labels only where the element needs them.
Status
A status is never color alone. It carries a dot, a word and a title.
