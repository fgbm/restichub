## How it works

<Diagram name="architecture" label="The connections between the browser, the control plane, the agents and the repositories" />

The agent opens the connection to the control plane. The control plane never connects to a host. The backup data goes from the host to the repository directly.

:::caution
ResticHub is pre-release. The MVP is built and is in acceptance testing on real hosts. There is no stable release yet, and the interfaces can still change.
:::
