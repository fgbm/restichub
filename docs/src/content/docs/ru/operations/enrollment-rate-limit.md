---
title: Предел частоты регистрации агентов
description: Предел частоты точки регистрации агентов за обратным прокси и за NAT.
---

Агенты регистрируются запросом `POST /agent/v1/enroll`. Это единственный адрес, для которого не нужен клиентский сертификат. Сервер управления ограничивает частоту запросов к нему, чтобы один клиент не мог перегрузить сервер.

## Предел

- С одного IP-адреса сервер управления принимает не больше 10 запросов регистрации в минуту.
- С одним префиксом токена регистрации сервер управления принимает не больше 10 запросов в минуту.
- На 11-й запрос сервер отвечает HTTP 429 и заголовком `Retry-After` со временем ожидания в секундах.

Префикс токена — первые восемь символов значения токена после `re_`. У одного токена один счётчик. Изменить тело запроса, чтобы обойти предел, не получится: счётчик учитывает только префикс.

## За обратным прокси

Сервер управления берёт адрес клиента из сетевого соединения. Заголовок `X-Forwarded-For` он учитывает, только если соединение пришло от доверенного прокси. Укажите сеть обратного прокси в `RESTICHUB_TRUSTED_PROXIES`: это список сетей в формате CIDR через запятую.

Если список пуст, сервер управления игнорирует `X-Forwarded-For`. Тогда у всех запросов через прокси адрес источника — адрес прокси, и предел считается для прокси целиком.

## За NAT

Предел считается по IP-адресу источника. Много хостов за одним NAT имеют один адрес и один общий счётчик, поэтому больше 10 хостов за одним NAT достигнут предела за минуту. Выдайте каждому хосту свой токен регистрации: предел по префиксу токена считается для каждого токена отдельно.

## Результат

- Один клиент не может перегрузить сервер.
- Для группы хостов за одним NAT или прокси нужно учесть общий адрес.
