---
title: Предел частоты регистрации агентов
description: Предел частоты точки регистрации агентов за обратным прокси и за NAT.
---

Сервер управления обслуживает регистрацию агентов на `POST /agent/v1/enroll`. Это единственная точка без клиентского сертификата (FR-ID-05). Сервер управления ограничивает частоту запросов, чтобы один клиент не мог завалить точку.

## Предел

- Сервер управления разрешает 10 запросов регистрации с одного IP-адреса за минуту.
- Сервер управления разрешает 10 запросов регистрации с одного префикса токена регистрации за минуту.
- 11-й запрос сверх предела даёт HTTP 429 и заголовок `Retry-After` со временем ожидания в секундах.

Префикс токена — первые восемь символов значения токена после `re_`. У одного токена один счётчик. Клиент не может обойти предел разными телами запросов, потому что счётчик читает префикс.

## За обратным прокси

Сервер управления читает адрес клиента из сокета. Он читает заголовок `X-Forwarded-For` только тогда, когда сокет принадлежит доверенному прокси. Задайте в `RESTICHUB_TRUSTED_PROXIES` сеть обратного прокси. Значение — список сетей в форме CIDR через запятую.

Пустой список заставляет сервер управления игнорировать `X-Forwarded-For`. Тогда каждый запрос от прокси содержит адрес прокси, и предел считает прокси.

## За NAT

Предел считает IP-адрес источника. Много хостов за одним NAT делят один IP-адрес. Они делят один счётчик. Парк более 10 хостов за одним NAT достигает предела за минуту. Выдайте каждому хосту свой токен регистрации. Предел префикса токена считается отдельно для каждого токена.

## Результат

- Один клиент не может завалить точку.
- Парку за одним NAT или прокси нужен план для общего адреса.
