---
title: Замена корневого удостоверяющего центра
description: Как оператор заменяет корневой удостоверяющий центр установки.
---

:::caution[Внимание]
Ни одна команда не выполняет эту процедуру. Агент хранит корневой сертификат, который он запомнил при регистрации, и ничто не обновляет его. После замены корневого удостоверяющего центра зарегистрируйте каждый агент заново.
:::

В установке есть один корневой удостоверяющий центр (CA). Корневой удостоверяющий центр подписывает один выпускающий удостоверяющий центр. Агенты доверяют корневому удостоверяющему центру. Замена корневого удостоверяющего центра меняет доверие каждого агента.

## Когда заменять корневой удостоверяющий центр

Замените корневой удостоверяющий центр, если:

- корневой сертификат скоро истекает (он действует 10 лет);
- корневой ключ могли скомпрометировать.

Сервер управления сам заменяет выпускающий удостоверяющий центр. Не заменяйте выпускающий удостоверяющий центр вручную.

## Перед началом

- Запланируйте окно обслуживания. Каждый агент должен зарегистрироваться заново, поэтому до конца работ ни один агент не выполняет задания.
- Сделайте копию базы данных сервера управления и ключа шифрования ключей (KEK). Храните копию KEK отдельно от копии базы данных.
- Создайте по одному токену регистрации для каждого хоста. См. [Регистрация агента](/restichub/ru/getting-started/add-a-host/).

## Порядок действий

1. Остановите сервер управления.
2. Подключитесь к базе данных от имени роли-владельца.
3. Удалите все строки таблицы `ca_keys`.
4. Запустите сервер управления. Он создаст новый корневой и новый выпускающий удостоверяющие центры.
5. Зарегистрируйте каждый агент заново с флагом `--force` и новым токеном регистрации. Агент запомнит новый корневой удостоверяющий центр.
6. Когда появятся новые записи хостов, отзовите старые. См. [Отзыв агента](/restichub/ru/guides/agent-revocation/).

## Результат

- Агенты доверяют новому корневому удостоверяющему центру.
- Сервер управления подписывает сертификаты агентов новым выпускающим удостоверяющим центром.
- Если корневой удостоверяющий центр истёк, сервер управления не запускается и выводит сообщение. В этом случае выполните эту процедуру.
