В установке есть один корневой удостоверяющий центр (CA). Корневой удостоверяющий центр подписывает один выпускающий удостоверяющий центр. Агенты доверяют корневому удостоверяющему центру. Замена корневого удостоверяющего центра меняет доверие каждого агента.

## Когда заменять корневой удостоверяющий центр

Заменяйте корневой удостоверяющий центр в этих случаях:

- Корневой сертификат скоро истекает. Корневой удостоверяющий центр живёт 10 лет.
- Возможна компрометация корневого ключа.

Сервер управления сам заменяет выпускающий удостоверяющий центр. Не заменяйте выпускающий удостоверяющий центр вручную.

## Перед началом

- Запланируйте окно обслуживания. Во время замены каждый агент должен доверять новому корневому удостоверяющему центру.
- Сохраните старый корневой сертификат. Агент ещё может предъявить старую цепочку.
- Сделайте копию базы данных сервера управления и ключа шифрования ключей (KEK).

## Порядок действий

1. Создайте новый корневой удостоверяющий центр со сроком жизни 10 лет.
2. Создайте новый выпускающий удостоверяющий центр и подпишите его новым корневым.
3. Добавьте новый корневой сертификат в хранилище доверия каждого агента.
4. Дождитесь, когда каждый агент сообщит новое хранилище доверия.
5. Замените строку корневого удостоверяющего центра в базе данных сервера управления.
6. Перезапустите сервер управления. При запуске сервер управления проверяет корневой удостоверяющий центр.
7. Удалите старый корневой сертификат из хранилища доверия каждого агента.
8. Удалите старую строку корневого удостоверяющего центра.

## Результат

- Агенты доверяют новому корневому удостоверяющему центру.
- Сервер управления подписывает сертификаты агентов новым выпускающим удостоверяющим центром.

Запуск с истёкшим корневым удостоверяющим центром отказывает с сообщением. Тогда выполните эту процедуру.
