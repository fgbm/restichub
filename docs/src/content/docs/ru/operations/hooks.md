---
title: Хуки из списка разрешённых
description: Как администратор хоста перечисляет программы, которые профиль может запускать на хосте до и после резервного копирования.
---

Хук из списка разрешённых — это программа, которую администратор хоста указывает в файле на хосте. Профиль ссылается на хук по его ID и отправляет типизированные параметры. Агент запускает только программы из файла.

Используйте этот режим, если не хотите, чтобы сервер управления отправлял код на хост. Хост с [режимом доверия](scripts/) может выполнять и скрипты сервера. Профиль может использовать оба вида.

## Файл списка

| Система | Файл |
|---|---|
| Linux | `/etc/restichub-agent-hooks.toml` |
| Windows | `%ProgramData%\ResticHub\Agent-hooks.toml` |

Агент доверяет файлу, только если им владеет root или администраторы. Никакая другая учётная запись не может записать файл, указанную в нём программу или каталог выше них. Если файл небезопасен, агент не запускает ни одного хука и сообщает состояние `insecure`. Задание, сервер управления и самообновление не могут изменить файл.

Агент читает файл заново для каждого задания. Изменение действует со следующего задания.

## Формат

Файл написан на TOML. Неизвестный ключ — это ошибка, поэтому опечатка никогда не ослабит правило.

```toml
[[hook]]
id = "pg_dump"
executable = "/usr/bin/pg_dump"
args = ["--format=custom"]
timeout_seconds = 600
phases = ["before"]

[[hook.parameter]]
name = "database"
type = "string"
pattern = "[a-z_][a-z0-9_]*"
required = true
pass_as = "positional"
position = 1

[[hook.parameter]]
name = "password"
type = "secret_ref"
pass_as = "env"
env_name = "PGPASSWORD"
```

У хука есть такие ключи:

| Ключ | Значение |
|---|---|
| `id` | Имя, которое использует профиль. От 1 до 64 символов из `a-z`, `0-9`, `.`, `_` и `-`. |
| `executable` | Абсолютный путь к программе. Агент запускает её без оболочки. |
| `args` | Неизменные аргументы. |
| `timeout_seconds` | Лимит времени. По умолчанию 300 секунд. Максимум — 24 часа. |
| `working_dir` | Рабочий каталог. По умолчанию — каталог программы. |
| `phases` | Фазы, в которых хук может выполняться. Пустой список разрешает любую фазу. |
| `env` | Неизменные переменные окружения. |

У параметра есть тип: `string`, `integer`, `enum`, `boolean` или `secret_ref`. У строки могут быть `max_length` и `pattern`, которому должно соответствовать всё значение. У целого числа могут быть `minimum` и `maximum`. У перечисления есть список `values`. Ключ `pass_as` определяет, как значение попадает в программу: `flag`, `positional` или `env`. Секрет всегда использует `env`.

## Использование хука в профиле

Агент сообщает ID, фазы и типы параметров каждого хука, но никогда не сообщает путь. Форма профиля предлагает хуки, которые сообщают все целевые хосты. Сервер управления не сохраняет профиль с хуком, которого нет на целевом хосте. Ошибка называет хост и хук.

Фазы — `before`, `after`, `on_success`, `on_error` и `finally`. Для них действуют те же правила, что и для фаз [скриптов сервера](scripts/). Хук `before` с ошибкой останавливает резервное копирование.

Каждый хук — это шаг задания со своим журналом, как и скрипт.
