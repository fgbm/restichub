---
title: Хуки из списка разрешённых
description: Как администратор хоста перечисляет программы, которые профиль может запускать на хосте до и после резервного копирования.
---

Хук из списка разрешённых — это программа, которую администратор хоста перечисляет в файле на хосте. Профиль ссылается на хук по идентификатору и передаёт типизированные параметры. Агент запускает только программы из этого файла.

Используйте этот режим, если не хотите, чтобы сервер управления присылал на хост код. Хост с [режимом доверия](scripts/) может выполнять и скрипты сервера. В профиле можно использовать оба вида.

## Файл списка

| Система | Файл |
|---|---|
| Linux | `/etc/restichub-agent-hooks.toml` |
| Windows | `%ProgramData%\ResticHub\Agent-hooks.toml` |

Агент доверяет файлу, только если его владелец — root или администраторы, а другие учётные записи не могут записывать ни в файл, ни в указанные в нём программы, ни в каталоги над ними. Если файл небезопасен, агент не запускает ни одного хука и сообщает состояние `insecure`. Задание, сервер управления и самообновление изменить файл не могут.

Агент читает файл заново перед каждым заданием, поэтому изменение действует со следующего задания.

## Формат

Файл написан на TOML. Неизвестный ключ считается ошибкой, поэтому опечатка не ослабит правило.

```toml
[[hook]]
id = "pg_dump"
executable = "/usr/bin/pg_dump"
args = ["--format=custom"]
timeout_seconds = 600
phases = ["before"]

[[hook.parameter]]
name = "database"
type = "string"
pattern = "[a-z_][a-z0-9_]*"
required = true
pass_as = "positional"
position = 1

[[hook.parameter]]
name = "password"
type = "secret_ref"
pass_as = "env"
env_name = "PGPASSWORD"
```

У хука есть такие ключи:

| Ключ | Значение |
|---|---|
| `id` | Имя, на которое ссылается профиль. От 1 до 64 символов из `a-z`, `0-9`, `.`, `_` и `-`. |
| `executable` | Абсолютный путь к программе. Агент запускает её напрямую, без оболочки. |
| `args` | Неизменные аргументы. |
| `timeout_seconds` | Лимит времени. По умолчанию — 300 секунд, наибольшее значение — 24 часа. |
| `working_dir` | Рабочий каталог. По умолчанию — каталог программы. |
| `phases` | Фазы, в которых хук может выполняться. Если список пуст, разрешены все фазы. |
| `env` | Неизменные переменные окружения. |

У параметра есть тип — `string`, `integer`, `enum`, `boolean` или `secret_ref`. Для строки можно задать `max_length` и `pattern`, которому должно соответствовать всё значение. Для целого числа — `minimum` и `maximum`. Для перечисления нужен список `values`. Ключ `pass_as` определяет, как значение передаётся в программу: `flag`, `positional` или `env`. Секрет всегда передаётся через `env`.

## Использование хука в профиле

Агент сообщает идентификатор, фазы и типы параметров каждого хука, но не сообщает путь. Форма профиля предлагает только те хуки, о которых сообщили все целевые хосты. Профиль с хуком, которого нет на целевом хосте, сервер управления не сохранит; в ошибке указаны хост и хук.

Фазы — `before`, `after`, `on_success`, `on_error` и `finally`. Для них действуют те же правила, что и для фаз [скриптов сервера](scripts/). Если хук `before` завершился с ошибкой, резервное копирование не запускается.

Каждый хук, как и скрипт, — отдельный шаг задания со своим журналом.
