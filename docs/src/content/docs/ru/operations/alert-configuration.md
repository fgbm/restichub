Для оповещений нужны четыре настройки. Они общие для всей установки, а не для организации. Задайте их в файле конфигурации или в переменных окружения; переменная окружения имеет приоритет над файлом. Все переменные сервера управления перечислены на странице [Переменные окружения](/restichub/ru/operations/environment-variables/).

## Публичный адрес

Публичный адрес — это начало URL всех ссылок в сообщениях.

| Ключ в файле | Переменная окружения | Значение |
|---|---|---|
| `public_origin` | `RESTICHUB_PUBLIC_ORIGIN` | Схема, хост и порт веб-интерфейса, например `https://backup.example.com`. |

Значение не должно содержать имя пользователя, путь и параметры. Если адрес не задан, в сообщениях не будет ссылок.

## Язык сообщений

Письма и сообщения вебхуков отправляются на одном языке для всей установки. В веб-интерфейсе оповещения показываются на языке пользователя.

| Ключ в файле | Переменная окружения | Значение |
|---|---|---|
| `notifications.language` | `RESTICHUB_NOTIFICATIONS_LANGUAGE` | `en` (по умолчанию) или `ru`. |

В сообщение вебхука также входят поля, чтобы получатель мог составить собственный текст. Поле `params` содержит типизированные значения. Поле `error_text` содержит стабильный код ошибки задания или очищенный текст ошибки, если у задания нет кода. Поле `error_label` содержит слова для известного кода на языке установки. Поле `error_text` не зависит от языка. Письмо показывает слова на языке установки.

## SMTP-сервер

Каналы электронной почты отправляют письма через один SMTP-сервер. Без него письма не отправляются.

| Ключ в файле | Переменная окружения | Значение |
|---|---|---|
| `smtp.host` | `RESTICHUB_SMTP_HOST` | Имя хоста SMTP-сервера. Если оно задано, почта включается. |
| `smtp.port` | `RESTICHUB_SMTP_PORT` | Порт. По умолчанию 587 для `starttls`, 465 для `tls` и 25 для `none`. |
| `smtp.security` | `RESTICHUB_SMTP_SECURITY` | `starttls` (по умолчанию), `tls` или `none`. |
| `smtp.username` | `RESTICHUB_SMTP_USERNAME` | Имя пользователя. Если оно не задано, сервер управления не входит на SMTP-сервер. |
| `smtp.password_file` | `RESTICHUB_SMTP_PASSWORD_FILE` | Путь к файлу с паролем. |
| — | `RESTICHUB_SMTP_PASSWORD` | Пароль. Используйте его вместо файла; оба варианта сразу задавать нельзя. |
| `smtp.from` | `RESTICHUB_SMTP_FROM` | Адрес отправителя. Обязателен, если задан хост. |

Правила для пароля:

- Пароль не сохраняется в базе данных и не попадает в журнал аудита.
- В рабочей установке используйте файл: это должен быть обычный файл, который может читать только его владелец.
- Сервер управления входит командой `AUTH PLAIN` и только по TLS. Если задан пароль и выбрано `none`, сервер управления не запускается.
- Если SMTP-сервер отклоняет часть получателей, но принимает остальных, письмо считается отправленным. В записи доставки остаётся пометка с числом отклонённых получателей.
- Сервер управления проверяет сертификат SMTP-сервера по системным корневым сертификатам и по встроенным публичным.

Пример:

```toml
public_origin = "https://backup.example.com"

[smtp]
host = "smtp.example.com"
security = "starttls"
username = "restichub"
password_file = "/run/secrets/smtp-password"
from = "restichub@example.com"
```

## Список разрешённых сетей вебхуков

По умолчанию вебхук должен использовать `https` и публичный адрес. Администратор может смягчить эти два правила.

| Ключ в файле | Переменная окружения | Значение |
|---|---|---|
| `webhook.allow_http` | `RESTICHUB_WEBHOOK_ALLOW_HTTP` | Разрешает схему `http`. По умолчанию `false`. |
| `webhook.allow_networks` | `RESTICHUB_WEBHOOK_ALLOW_NETWORKS` | Сети в формате CIDR, которые проверка адреса пропускает. В переменной окружения разделяйте записи запятыми. |

Проверка адреса всегда отклоняет диапазоны loopback, частные, локальные, общего пользования, зарезервированные и многоадресные. Она также отклоняет диапазоны `2001::/23` (в нём Teredo), `64:ff9b:1::/48` и `192.88.99.0/24`. Кнопка проверки канала ограничена: 6 проверок в минуту на пользователя и 20 в минуту на организацию.

Сеть из списка действует для всех организаций установки. Добавляйте самую маленькую сеть, в которую входит получатель.

```toml
[webhook]
allow_networks = ["10.20.30.0/24"]
```

> **Предупреждение:** Список разрешённых сетей позволяет Администратору любой организации отправлять запросы с сервера управления в эту сеть. Добавляйте сеть, только если доверяете всем Администраторам установки.
