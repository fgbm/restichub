Пакет агента не содержит restic. Пакет и restic — две отдельные загрузки. Агент скачивает и проверяет restic сам (ADR-0038). Команды описаны в разделе [Регистрация агента](register-an-agent.md).

## Состав пакета

Каждый пакет хранит эти файлы:

- `restichub-agent` или `restichub-agent.exe` — бинарный файл агента.
- `LICENSE` — лицензия ResticHub, Apache License 2.0.
- `THIRD_PARTY_NOTICES` — пояснение, что агент скачивает restic, и отпечаток ключа подписи выпусков restic внутри агента.
- `SHA256SUMS` — сумма SHA-256 каждого файла выше.

Формат пакета — `tar.gz` на Linux и `zip` на Windows. Имя пакета — `restichub-agent-<version>-<os>-<arch>`. Рабочий процесс публикует как артефакты только эти пакеты. Шаг сборки передаёт результат шагу упаковки как промежуточный артефакт, который удаляется через один день.

## Цепочка проверки агента

Когда агент скачивает restic, он выполняет эту цепочку:

1. Он читает тег последнего выпуска с GitHub.
2. Он загружает архив, `SHA256SUMS` и `SHA256SUMS.asc` со страницы выпуска по HTTPS с проверкой сертификата.
3. Он проверяет подпись OpenPGP файла `SHA256SUMS` ключом подписи выпусков. Ключ входит в состав агента, и учитывается только ключ с закреплённым отпечатком.
4. Он проверяет, что `SHA256SUMS` содержит архив и что сумма SHA-256 архива равна указанной.
5. Он проверяет версию: restic 0.18.1 или новее и основная версия 0.
6. Он распаковывает бинарный файл и запускает его с командой `version`. Напечатанная версия должна равняться версии архива.
7. Он сохраняет бинарный файл в защищённом каталоге и записывает версию и сумму SHA-256 в защищённую запись.

Отпечаток — `CF8F 18F2 8445 7597 3F79 D4E1 91A6 868B D3F7 A907`. Этот отпечаток указан в документе установки restic. Файл `packaging/restic-release-key.asc` хранит открытый ключ. Тест проверяет, что закреплённое значение внутри агента равно значению в `packaging/restic.env`.

## Restic для тестов

Тесты CI, которым нужен настоящий restic, используют скрипт `packaging/fetch-restic.sh`. Файл `packaging/restic.env` хранит закреплённую версию и отпечаток. Целевую версию задаёт ADR-0011. Закреплена версия restic 0.19.1. Скрипт выполняет ту же цепочку с `gpg`. Пакета агента он не касается.

Еженедельный рабочий процесс (`.github/workflows/restic-latest.yml`) запускает тесты с настоящим restic на последнем выпуске restic. Изменение JSON-вывода restic обнаруживается там до того, как оператор обновит restic.

## Смена закреплённой версии

1. Измените `RESTIC_VERSION` в файле `packaging/restic.env`.
2. Запустите `packaging/fetch-restic.sh` для каждой целевой платформы.
3. Запустите CI.

## Проверка пакета

Рабочий процесс `.github/workflows/agent-packages.yml` собирает каждую целевую платформу. Один шаг распаковывает каждый пакет. Он проверяет, что пакет содержит агент, `LICENSE`, `THIRD_PARTY_NOTICES` и `SHA256SUMS`, что суммы совпадают и что в пакете нет restic (AC-IN-01).
