Пакет агента хранит агент и бинарный файл restic. Агент использует только встроенный restic (ADR-0031). Установка на хосте не может изменить проверенную версию restic.

## Состав пакета

Каждый пакет хранит эти файлы:

- `restichub-agent` или `restichub-agent.exe` — бинарный файл агента.
- `restic` или `restic.exe` — закреплённый бинарный файл restic.
- `LICENSE` — лицензия ResticHub, Apache License 2.0.
- `THIRD_PARTY_NOTICES` — текст лицензии restic, BSD 2-Clause License.
- `SHA256SUMS` — сумма SHA-256 каждого файла выше.

Формат пакета — `tar.gz` на Linux и `zip` на Windows. Имя пакета — `restichub-agent-<version>-<os>-<arch>`.

## Закреплённая версия

Файл `packaging/restic.env` хранит закреплённую версию restic и отпечаток ключа подписи выпуска. Версию задаёт ADR-0011. Закреплена версия restic 0.19.1.

Отпечаток — `CF8F 18F2 8445 7597 3F79 D4E1 91A6 868B D3F7 A907`. Этот отпечаток указан в документе установки restic. Файл `packaging/restic-release-key.asc` хранит открытый ключ.

## Цепочка проверки

Скрипт `packaging/fetch-restic.sh` выполняет эту цепочку:

1. Он загружает `SHA256SUMS` и `SHA256SUMS.asc` со страницы выпуска restic.
2. Он импортирует открытый ключ из `packaging/restic-release-key.asc`. Сервер ключей он не использует.
3. Он проверяет подпись файла `SHA256SUMS`. Он отказывает подписи другого ключа.
4. Он загружает архив для целевой платформы. Он сравнивает сумму SHA-256 архива с `SHA256SUMS`.
5. Он распаковывает бинарный файл и печатает его сумму SHA-256.
6. Он загружает архив исходного кода выпуска. Он проверяет архив и извлекает текст лицензии restic.

Сборка агента читает напечатанную сумму SHA-256 из переменной `RESTICHUB_RESTIC_SHA256`. Агент встраивает это значение. При запуске агент считает сумму встроенного restic и отказывает другому бинарному файлу (T20).

Рабочий процесс `.github/workflows/agent-packages.yml` выполняет цепочку для каждой целевой платформы. Один шаг распаковывает каждый пакет и проверяет состав и сумму restic (AC-IN-01).

## Смена закреплённой версии

1. Измените `RESTIC_VERSION` в файле `packaging/restic.env`.
2. Запустите `packaging/fetch-restic.sh` для каждой целевой платформы.
3. Запустите рабочий процесс пакетов агента.
