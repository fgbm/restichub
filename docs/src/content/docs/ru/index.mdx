ResticHub — сервер управления резервным копированием [restic](https://restic.net) на парке хостов.

:::caution[Внимание]
ResticHub на этапе проектирования. Готового релиза пока нет.
:::

## Что делает ResticHub

- Сервер управления хранит все профили, расписания и секреты.
- Сервер управления решает, когда запустить задание.
- Агент на каждом хосте запускает restic и отправляет результаты на сервер управления.
- Агент получает секреты репозитория только на одно задание.
- Хуки запускаются только из списка разрешённых хуков на хосте.

Основные термины описаны в разделе [Основные понятия](concepts/overview/).
