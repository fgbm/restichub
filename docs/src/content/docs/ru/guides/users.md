---
title: Пользователи
description: Как управлять учётными записями, членством и паролями пользователей.
---

Учётная запись действует во всей установке. Пользователь входит по имени пользователя и паролю. У учётной записи есть членство в одной или нескольких организациях. У каждого членства одна роль. Право администратора платформы — это право учётной записи, а не роль в организации.

## Пользователи организации

Администратор организации управляет пользователями этой организации.

1. Откройте «Настройки», затем «Пользователи».
2. Нажмите на имя пользователя. Откроется страница пользователя.
3. Выберите роль в разделе «Доступ». Изменение применяется сразу. Текст под полем описывает права роли.

В меню «…» страницы есть пункт «Отключить пользователя». Членство отключается, и пользователь не может работать в этой организации. Учётная запись остаётся. Чтобы вернуть доступ, выберите «Включить пользователя».

В меню «…» списка есть пункты «Изменить роль», «Сбросить пароль» и «Отключить пользователя».

Некоторые действия недоступны:

- Администратор не может изменить свою роль, отключить себя и сбросить свой пароль.
- Администратор не может сбросить пароль общей учётной записи. У общей учётной записи есть членство в другой организации. Её пароль сбрасывает сам пользователь или администратор платформы.
- Администратор не может изменить учётную запись с правом администратора платформы. Ей управляет только администратор платформы.

У каждого недоступного действия экран показывает причину.

## Пользователи платформы

Администратор платформы управляет всеми учётными записями установки.

1. Откройте «Администрирование платформы», затем «Пользователи».
2. Нажмите на имя пользователя. Откроется страница пользователя.

Таблица «Членство» показывает организации пользователя:

- Чтобы изменить роль, выберите роль в строке. Изменение применяется сразу. Если изменение не прошло, поле снова показывает роль, которую хранит сервер управления.
- Чтобы убрать членство, нажмите на значок удаления и подтвердите.
- Чтобы добавить членство, выберите организацию и роль под таблицей. Затем нажмите «Добавить организацию». В списке есть только активные организации, где у пользователя нет членства.

У членства может быть отметка «Отключён» или «Приостановлена». «Отключён» значит, что администратор той организации отключил членство. «Приостановлена» значит, что организация приостановлена.

Право администратора платформы не даёт доступа к данным организации. Чтобы работать в организации, добавьте членство своей учётной записи.

## Сброс пароля

1. Откройте страницу пользователя.
2. Нажмите «Сбросить пароль».
3. Введите новый пароль не короче 12 символов.
4. Нажмите «Сбросить пароль».

Старый пароль перестаёт действовать, и все сеансы учётной записи завершаются. Аудит платформы и аудит каждой организации учётной записи записывают сброс без пароля.

Сброс не отзывает API-токены, которые создала эта учётная запись. Чтобы закрыть учётной записи весь доступ, отзовите эти токены отдельно.

Администратор платформы может сбросить пароль другого администратора платформы.

Администратор платформы не может сбросить свой пароль на этой странице. Чтобы изменить свой пароль, отправьте `POST /api/v1/auth/password` с текущим паролем.

## Выдача и отзыв права администратора платформы

1. Откройте страницу пользователя.
2. Откройте меню «…» и выберите «Выдать право администратора платформы».
3. Введите новый пароль учётной записи и подтвердите.

Для выдачи права нужен новый пароль, потому что старый пароль может знать администратор организации. Старый пароль и все сеансы учётной записи перестают действовать.

Чтобы забрать право, выберите в меню «…» пункт «Забрать право администратора платформы» и подтвердите. Членство учётной записи не меняется.

Нельзя забрать своё право. Нельзя забрать право у последнего активного администратора платформы.

## Отключение учётной записи

1. Откройте страницу пользователя.
2. Откройте меню «…» и выберите «Отключить пользователя».
3. Подтвердите.

Пользователь не может войти ни в одну организацию. Все сеансы учётной записи завершаются. Членство и роли остаются. Чтобы вернуть доступ, выберите «Включить пользователя».

Нельзя отключить свою учётную запись. Нельзя отключить последнего активного администратора платформы.
