[Параметр профиля](/restichub/ru/concepts/profile-parameters/) хранит значение, которое отличается от хоста к хосту, например точку монтирования. Эта страница показывает, как объявить параметр и как задать ему значение. Шаги выполняет администратор или оператор. Секретное значение задаёт только администратор.

## Перед началом

- Профиль создан. См. [Создание профиля и плана](/restichub/ru/getting-started/profiles-and-plans/).
- Хост имеет состояние «В сети».
- Для секретного значения есть секрет с назначением `hook_secret`. См. [Скрипты сервера](/restichub/ru/guides/scripts/#параметры-и-секреты).

## Объявите параметр

1. Откройте профиль и найдите раздел «Параметры».
2. Нажмите «Добавить параметр». В таблице появится пустая строка.
3. Введите имя в поле «Параметр»: строчная латинская буква, затем строчные латинские буквы, цифры и подчёркивания, например `pg_dir`.
4. Выберите «Тип»: «Текст» или «Секрет».
5. Включите «Обязательный», если у плана должно быть значение.
6. Для текстового параметра введите значение «По умолчанию». Этот шаг необязателен.
7. Введите «Описание». Этот шаг необязателен.
8. Нажмите «Сохранить».

Результат: строка показывает параметр, число мест, где он используется, и тип.

У секретного параметра в столбце «По умолчанию» стоит «Не задаётся»: одно значение по умолчанию дало бы одинаковый пароль всем хостам.

Параметр можно объявить и из поля пути. Введите `{{` и имя в поле путей. Подсказка под полем сообщает «Параметр … не объявлен.» Нажмите «Объявить». Редактор добавит строку типа «Текст» с включённым «Обязательный». Измените строку, если параметру нужен другой тип.

## Используйте параметр в профиле

1. Откройте профиль.
2. Введите переменную в путь, исключение, файл исключений или тег, например `/srv/{{param.pg_dir}}`.
3. Нажмите «Сохранить».

Редактор профиля показывает список переменных, когда вы вводите `{{`. Группа «Параметры профиля» содержит объявленные параметры, группа «Переменные хоста» — остальные переменные. См. [Переменные шаблона](/restichub/ru/reference/variables/).

Секретный параметр остаётся в списке с причиной, по которой его нельзя подставить в путь или тег. Секрет, набранный вручную, даёт ошибку под полем, и сервер отклоняет сохранение.

## Задайте значение в плане

Сервер управления не сохраняет план, у которого нет значения обязательного параметра.

1. Откройте план и найдите раздел «Параметры профиля».
2. Нажмите «Задать для этого плана» в строке параметра.
3. Введите значение или выберите секрет для секретного параметра.
4. Нажмите «Задать».
5. Нажмите «Сохранить».

Результат: строка показывает значение и источник «план».

## Задайте значение на хосте

Страница хоста перечисляет параметры профилей планов этого хоста. Поэтому план должен существовать до того, как вы зададите значение на хосте.

1. Откройте «Хосты» и выберите имя хоста.
2. Найдите раздел «Значения параметров».
3. Введите значение в поле «Значение» или выберите секрет для секретного параметра.
4. Нажмите «Сохранить значения».

<Screen name="host-parameters" alt="Раздел «Значения параметров» хоста с текстовым значением, секретом и значением по умолчанию" />

Результат: значение читают все планы хоста. Предупреждение над таблицей называет план, который останется без обязательного значения, и сервер отклоняет такое изменение.

Наблюдатель видит имена параметров и имя каждого секрета. Текстовое значение скрыто.

## Перенесите значение плана на хост

1. Задайте значение на хосте. См. раздел выше.
2. Откройте план и найдите раздел «Параметры профиля».
3. Нажмите «Убрать значение плана» в строке.
4. Нажмите «Сохранить».

Результат: строка показывает значение хоста и источник «хост».

## Удалите значение или параметр

- Чтобы удалить значение хоста, нажмите значок удаления в строке параметра и затем «Сохранить значения». Обязательный параметр без другого значения остановит сохранение.
- Чтобы удалить значение плана, нажмите «Убрать значение плана» и затем «Сохранить».
- Чтобы удалить параметр, нажмите значок удаления в строке параметра в профиле и затем «Сохранить». Редактор перечислит планы, которые потеряют значение параметра, и запросит подтверждение.

Удалённый параметр сохраняет значения на хостах, и страница хоста помечает их «Не нужен профилям». Удалить параметр, который хост хранит как секретное значение, может только администратор.

## Отказы

| Сообщение или код | Причина | Что делать |
|---|---|---|
| «План нельзя сохранить: у параметра … нет значения.» | У обязательного параметра нет значения ни в плане, ни на хосте. | Задайте значение в плане или на хосте. |
| «Профиль не сохранён: планы останутся без обязательного параметра …» | Новый обязательный параметр или удалённое значение оставляет план без значения. | Задайте значение в этих планах и сохраните профиль снова. |
| «Значения не сохранены: планы останутся без обязательного параметра …» | Изменение значений хоста оставляет план без значения. | Задайте значение в этих планах и сохраните значения снова. |
| «Секретное значение задаёт только администратор.» | Оператор выбирает секрет. | Попросите администратора. |
| `parameter_kind_mismatch` | Тип значения не совпадает с объявлением. | Измените значение или объявление. |
| `parameter_not_declared` | Переменная называет параметр, которого нет в профиле. | Объявите параметр. |
| `parameter_needs_default` | Необязательный параметр без значения по умолчанию стоит в пути или теге. | Включите «Обязательный» или задайте значение по умолчанию. |
| `parameter_secret_in_template` | Секретный параметр стоит в пути, исключении или теге. | Используйте параметр в переменной скрипта. |
| `parameter_not_allowed` | Параметр стоит в правиле хранения или в проверке. | Уберите переменную из этого поля. |
