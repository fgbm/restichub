Организация хранит свои хосты, репозитории, профили, планы, секреты и пользователей. Одна организация не видит данные другой. Организациями установки управляет администратор платформы.

:::caution
В режиме `single` установка обслуживает одну организацию. Задайте `RESTICHUB_TENANCY_MODE=multi`, прежде чем создать вторую организацию. В режиме `single` сервер управления не запускается, если в базе данных больше одной активной организации.
:::

## Создание организации

1. Откройте меню организации на верхней панели и выберите «Администрирование платформы».
2. Откройте «Организации».
3. Нажмите «Создать организацию».
4. Введите имя. Имя содержит от 1 до 63 символов из `a-z`, `0-9` и `-`. Оно начинается с буквы и не равно `platform`.
5. Нажмите «Создать организацию».

Список показывает новую организацию с меткой «Нет администратора». Журнал аудита платформы содержит запись `tenant_create`.

В новой организации нет пользователей. Добавьте первого администратора на странице пользователя платформы. См. [Пользователи](/restichub/ru/guides/users/#пользователи-платформы).

## Приостановка и возобновление организации

Приостановленная организация не принимает вход и токены API своих пользователей. Её агенты остаются подключены.

1. Откройте «Организации».
2. В меню «…» организации выберите «Приостановить».

Чтобы снова сделать организацию активной, выберите «Возобновить» в том же меню. Журнал аудита содержит записи `tenant_suspend` и `tenant_resume`.

## Удаление организации

:::danger
Удаление стирает организацию и все её данные на сервере управления. Данные будут потеряны. Данные в репозиториях остаются.
:::

Удалить можно только приостановленную организацию.

1. Приостановите организацию.
2. В меню «…» организации выберите «Удалить».
3. Введите имя организации для подтверждения.
4. Нажмите «Удалить организацию».

Вкладка «Удалены» показывает организацию. Журнал аудита содержит запись `tenant_delete`.

## Переключение организации

Человек, который состоит в нескольких организациях, выбирает организацию на верхней панели.

1. Нажмите на имя организации на верхней панели.
2. Выберите другую организацию в меню.

После этого каждый экран показывает данные новой организации. Журнал аудита содержит запись `session_switch`.
