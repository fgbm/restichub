---

Токен API позволяет внешнему инструменту работать с API без сеанса. Токен принадлежит одной организации и имеет одну роль. Токенами управляет только администратор.

## Создание токена

1. Откройте «Настройки» → «Доступ» → «Токены API».
2. Нажмите «Создать токен».
3. Введите имя, например имя инструмента.
4. Выберите роль. Дайте самую узкую роль, которой хватит инструменту.
5. Выберите срок действия: «Никогда», «Через 30 дней», «Через 90 дней» или «Через 1 год».
6. Нажмите «Создать токен».
7. Скопируйте значение токена.

:::caution
Сервер управления показывает значение только один раз. Сохраните его в хранилище секретов инструмента. Если значение потеряно, отзовите токен и создайте новый.
:::

Список показывает токен с последним использованием и сроком действия. Выберите токен, чтобы увидеть его префикс, роль, состояние и даты. Вкладка «Истёкшие и отозванные» показывает токены, которые больше не работают.

## Использование токена

Передайте значение в заголовке `Authorization: Bearer rh_<token>`. См. [Справочник API](/restichub/ru/reference/api/#вход-с-токеном-api).

## Отзыв токена

Отзовите токен, когда инструменту он больше не нужен или когда значение мог узнать другой человек.

1. Откройте «Токены API».
2. В меню «…» токена выберите «Отозвать».
3. Нажмите «Отозвать» для подтверждения.

Инструменты с этим токеном сразу перестают работать. Журнал аудита содержит запись `api_token_revoke`.
