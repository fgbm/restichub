Список «Задания» показывает все задания организации. Состояния и правила очереди описаны в разделе [Жизненный цикл задания](/restichub/ru/concepts/job-lifecycle/).

Список «Задания» делит задания на вкладки «Все», «Выполняются», «Не выполнены», «С предупреждениями» и «Успешно». На каждой вкладке виден счётчик её заданий.

## Карточка задания

Выберите имя задания в списке «Задания». Откроется страница задания `/jobs/<id>`. Заголовок показывает план (или вид задания), статус, хост, источник запуска и, пока задание выполняется, номер шага. Кнопка «Запустить снова» запускает план ещё раз. Кнопка «Отменить задание» доступна, пока задание может измениться. Панель «О задании» содержит такие поля:

| Поле | Значение |
|---|---|
| Идентификатор | Идентификатор задания. |
| Вид | `backup`, `check`, `restore` и так далее. |
| План, Хост, Репозиторий | Объекты задания. |
| Запуск | «По расписанию», «Вручную» или «Обслуживание». |
| Поставлено в очередь | Время, когда задание попало в очередь. |
| Начало, Окончание | Время начала и окончания. |
| Принять до | Конец окна приёма. Поле видно, пока задание ждёт или отправлено. |
| Ограничение | Видно только у выполняющегося задания. Строка «Предел: ...» или «Без предела» показывает предельную длительность. Строка «Без прогресса: ...» показывает тайм-аут простоя. Если нет обоих ограничений, поле сообщает «Остановка, если restic не продвигается». |
| Попытка | Номер попытки. Поле появляется после повтора из-за блокировки. |
| Ключ подписи | Первые 8 символов идентификатора ключа, которым подписано задание. Кнопка рядом копирует идентификатор целиком. По нему можно найти задания ключа после [компрометации ключа](/restichub/ru/operations/job-signing-key-compromise/). |
| Длительность | Время выполнения. |

Панель «Шаги» перечисляет все шаги задания в порядке выполнения, в том числе шаги, которые не начались. У каждого шага виден его статус. У шага со скриптом есть метка «Скрипт» и его фаза. Выберите шаг, чтобы прочитать его журнал.

У невыполненного задания под заголовком видна причина. Статусы шагов и причины перечислены в разделе [Коды статусов и причин](/restichub/ru/reference/status-codes/).

## Отмена

Оператор может отменить задание. Чтобы отменить задание:

1. Откройте страницу задания.
2. Нажмите «Отменить задание».
3. В диалоге «Отменить задание?» нажмите «Отменить задание».

Результат зависит от состояния задания:

- Задание в очереди завершается сразу с результатом `cancelled`.
- Для отправленного или выполняющегося задания сервер управления помечает задание и отправляет агенту сообщение об отмене. Очередь никогда не отправляет помеченное задание. Если агент поздно подтверждает помеченное задание, сервер управления снова отправляет сообщение об отмене. Помеченное задание, которое агент так и не подтвердил, завершается с результатом `cancelled`, когда истекает время на подтверждение. Если агент выполняющегося задания не на связи, сервер управления отвечает HTTP 409 `agent_offline`.
- Задание `unlock_all` может отменить только Администратор.
- Задание в конечном состоянии отменить нельзя.
