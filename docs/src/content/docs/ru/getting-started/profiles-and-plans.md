---

Профиль описывает, что копировать. План выполняет профиль на хосте и пишет в репозиторий по расписанию. Эта страница создаёт один профиль и один план для первой резервной копии.

## Перед началом

- Хост имеет состояние «В сети» на экране «Хосты». См. [Добавление хоста](/restichub/ru/getting-started/add-a-host/).
- Репозиторий имеет состояние «Готов» на экране «Репозитории». См. [Добавление репозитория](/restichub/ru/getting-started/add-a-repository/).
- Хост может связаться с репозиторием. Для локального репозитория этот хост должен быть хостом репозитория. См. [Репозитории](/restichub/ru/concepts/repositories/).

## Создание профиля

1. Откройте экран «Профили» и выберите «Добавить профиль».
2. В разделе «Основное» укажите имя в поле «Профиль».
3. В разделе «Что копировать» укажите по одному пути в каждой строке. Путь в разделе «Все системы» действует на каждом хосте. Путь в разделе «Windows», «Linux» или «macOS» действует только на этой системе.
4. В разделе «Исключения» укажите шаблоны и пути, которые нужно пропустить. Этот шаг необязателен.
5. В разделе «Хранение» выберите набор: «Минимум», «Стандарт» или «Долго». Набор задаёт правила, по которым остаются снимки. См. [Правила хранения](/restichub/ru/concepts/profiles/#правила-хранения).
6. Выберите «Сохранить».

Результат: профиль появился в списке, а боковая панель «Что получится» показывает сводку профиля.

## Создание плана

1. Откройте экран «Планы» и выберите «Добавить план».
2. В разделе «Основное» укажите имя в поле «План».
3. В разделе «Что копировать» выберите профиль в поле «Профиль», репозиторий в поле «Репозиторий» и хост в поле «Хост».
4. В разделе «Расписание» задайте «Выражение cron» и «Часовой пояс» или выберите набор: «Каждый час», «Ежедневно в 02:00» или «По воскресеньям в 03:00». Переключатель «Запускать по расписанию» оставьте включённым.
5. В разделе «Допустимая потеря данных» укажите часы в поле «Допустимая потеря данных, RPO (часы)»: после этого срока копия считается просроченной. Этот шаг необязателен. По умолчанию значение равно интервалу расписания плюс запас. См. [Допустимая потеря данных (RPO)](/restichub/ru/guides/alerts/#допустимая-потеря-данных-rpo).
6. Выберите «Сохранить».

Результат: план появился в списке и показывает следующий запуск.

Сервер управления собирает профиль для операционной системы хоста. Профиль без пути для этой системы отклоняется.

## Значение параметра

Профиль может объявить параметр, например точку монтирования. План не сохраняется, пока у каждого обязательного параметра нет значения. Значение задают на хосте или в плане.

1. На странице плана откройте раздел «Параметры профиля».
2. Прочитайте источник каждого значения: «план», «хост» или «по умолчанию».
3. Если в строке стоит «не задано», нажмите «Задать на хосте» или «Задать для этого плана».
4. Нажмите «Сохранить».

См. [Параметры профиля](/restichub/ru/concepts/profile-parameters/).

## Запуск плана

1. Откройте меню «…» плана и выберите «Запустить сейчас».
2. Откройте экран «Задания». Когда агент завершит работу, задание получит состояние «Успешно».

См. [Просмотр и отмена заданий](/restichub/ru/guides/jobs/).
