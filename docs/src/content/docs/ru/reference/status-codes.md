На этой странице перечислены коды, которые сервер управления хранит для задания и его шагов. Состояния задания описаны в разделе [Жизненный цикл задания](/restichub/ru/concepts/job-lifecycle/#состояния-задания).

## Статусы шагов

| Код | Текст в веб-интерфейсе |
|---|---|
| `cancelled` | Отменено |
| `config_error` | Ошибка настройки |
| `failed` | Ошибка |
| `retry` | Репозиторий заблокирован |
| `skipped` | Пропущено |
| `success` | Успешно |
| `warning` | Предупреждение |

## Отклонённые задания

Если сервер управления не может собрать задание, задание завершается с кодом причины:

| Причина | Значение |
|---|---|
| `compile_failed` | Команды из профиля для этого агента построить нельзя. |
| `agent_facts_invalid` | Сведения об агенте неверны. |
| `agent_capability_missing` | Агент слишком старый для шага. Он не знает поле, которое нужно шагу. |
| `forget_without_tags` | У шага политики хранения нет фильтра по тегам. Сервер управления такой шаг не отправляет. |
| `step_missing` | В профиле больше нет шага этого задания. |
| `agent_revoked` | Агент отозван. |
| `plan_missing`, `plan_changed` | План удалён или перенесён на другой агент. |
| `profile_missing`, `repository_missing`, `repository_changed` | Объект задания удалён или изменён. |
| `secret_unavailable` | Секрет репозитория нельзя прочитать. |
| `signing_failed` | Сервер управления не смог подписать задание. |

## Причины и коды результата

У задания с ошибкой или отказом на странице задания под заголовком стоит причина. Вот эти тексты:

| Код | Текст в веб-интерфейсе |
|---|---|
| `agent_capability_missing` | Агент слишком старый для этого задания. Обновите агент. |
| `agent_facts_invalid` | Сведения о хосте непригодны. |
| `agent_lost` | Хост отключился во время задания. |
| `agent_revoked` | Хост отозван. |
| `cancelled` | Задание отменено. |
| `compile_failed` | Профиль больше не подходит этому хосту. |
| `expired` | Задание ждало слишком долго и истекло. |
| `forget_selected_nothing` | forget не выбрал ни одного снимка |
| `forget_without_tags` | У политики хранения нет фильтра по тегам. Задание не отправлено. |
| `hook_failed` | Скрипт или хук завершился ошибкой. |
| `interrupted` | Прервано: агент перезапустился во время скриптов |
| `job_invalid` | Задание не прошло проверку. |
| `listing_missing` | Хост не прислал результат этого запроса. |
| `lock_retries_exhausted` | Репозиторий оставался заблокированным после всех повторов. |
| `lock_retry` | Репозиторий был заблокирован. Новая попытка стоит в очереди. |
| `max_duration_exceeded` | Задание остановлено: оно шло дольше предельной длительности. |
| `not_acknowledged` | Хост не подтвердил получение задания. |
| `plan_changed` | План перенесён на другой хост. |
| `plan_missing` | План удалён. |
| `profile_missing` | Профиль удалён. |
| `repository_changed` | Профиль теперь использует другой репозиторий. |
| `repository_locked` | Репозиторий заблокирован другим процессом. |
| `repository_missing` | Репозиторий удалён. |
| `request_missing` | У задания нет запроса. |
| `restore_target_denied` | Хост отклонил путь назначения. Он вне корней восстановления или содержит файл агента. |
| `secret_unavailable` | Секрет репозитория недоступен. |
| `signed_job_unavailable` | Сохранённое задание нечитаемо. |
| `signing_failed` | Сервер управления не смог подписать задание. |
| `stalled` | Задание остановлено: restic слишком долго не продвигался. |
| `step_failed` | restic остановился с ошибкой. |
| `step_missing` | В профиле больше нет этого шага. |
| `step_not_started` | restic не запустился. Причина в журнале задания. |
| `succeeded_with_warnings` | Завершено с предупреждениями. |
| `timed_out` | Задание выполнялось дольше предельной длительности. |
| `unacknowledged_expired` | Хост не подтвердил задание до его истечения. |
| `unsupported_kind` | Очередь не выполняет задания этого вида. |
| `wrong_password` | Пароль репозитория или ключи доступа неверны. |

Оповещение о невыполненном задании использует короткий текст кода:

| Код | Текст в оповещении |
|---|---|
| `agent_lost` | хост отключился |
| `cancelled` | отменено |
| `expired` | срок задания истёк |
| `hook_failed` | ошибка скрипта или хука |
| `interrupted` | прервано перезапуском агента |
| `max_duration_exceeded` | превышена предельная длительность |
| `repository_locked` | репозиторий заблокирован |
| `repository_missing` | репозиторий не найден |
| `stalled` | нет прогресса |
| `step_failed` | ошибка restic |
| `step_not_started` | restic не запустился |
| `wrong_password` | неверный пароль или ключи |
