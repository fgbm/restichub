---
title: Глоссарий
description: Термины ResticHub, у каждого из которых одно значение.
---

Документация и веб-интерфейс используют эти термины. Один термин обозначает одно понятие.

| Термин | Значение |
|---|---|
| агент | Программа ResticHub на хосте. Запускает restic и отправляет результат. |
| сервер управления | Сервер ResticHub. Хранит расписание, секреты и журнал аудита. |
| хост | Компьютер с агентом. |
| организация | Единица изоляции в одной установке. Владеет хостами, репозиториями, планами, профилями, секретами и участниками. |
| репозиторий | Репозиторий restic. |
| профиль | Описание резервного копирования: пути, исключения, параметры и хранение. |
| план | Профиль, который запускается на хосте по расписанию. |
| задание | Один запуск плана или одна ручная операция. |
| шаг | Одна команда в задании. |
| снимок | Снимок restic. |
| резервная копия | Данные, сохранённые restic. |
| хост обслуживания | Хост, который выполняет `forget`, `prune` и `check` для репозитория. |
| хост репозитория | Хост, на диске которого лежит путь локального репозитория. Это хост обслуживания репозитория, и все задания репозитория выполняются на нём. |
| исключительная операция | Операция, которой нужен весь репозиторий: `init`, `check`, `forget`, `prune` и `unlock`. |
| регистрация агента | Первое подключение агента к серверу управления. |
| токен регистрации | Одноразовое значение, с которым агент регистрируется. |
| порт агентов | Отдельный порт сервера управления. Агенты подключаются к нему по mTLS. |
| отозвать | Сделать сертификат агента недействительным. |
| время на подтверждение | Срок, за который агент должен подтвердить принятое задание. |
| скрипт сервера | Скрипт, который вы пишете в веб-интерфейсе. Сервер управления подписывает его, агент выполняет. |
| режим доверия | Локальная настройка хоста, которая разрешает скрипты сервера. По умолчанию выключена. |
| KEK | Ключ шифрования ключей. Защищает все секреты в базе данных. |
| токен API | Секретное значение, которое скрипт передаёт при вызове API. |
