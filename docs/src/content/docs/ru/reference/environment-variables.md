title: Переменные окружения
description: Все переменные RESTICHUB_, которые читают сервер управления и агент, со значением по умолчанию, единицей измерения и назначением.
---

Сервер управления читает файл конфигурации (TOML) и переменные окружения с префиксом `RESTICHUB_`. Переменная окружения переопределяет то же значение из файла. Агент читает одну переменную `RESTICHUB_`. Значение «в секундах» — целое число секунд.

Задавайте переменные в окружении процесса сервера управления. В стеке Docker Compose добавьте их в раздел `environment` службы `cp` или передайте через файл `.env` (см. [Установка сервера управления](/restichub/ru/getting-started/install-control-plane/)).

## Сервер управления: основное

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `RESTICHUB_CONFIG` | нет | Путь к файлу конфигурации. Параметр командной строки `--config` главнее. |
| `RESTICHUB_LISTEN_ADDR` | `127.0.0.1:8080` | Адрес и порт веб-интерфейса и API. |
| `RESTICHUB_LOG_FORMAT` | `text` | Формат журнала: `text` или `json`. |
| `RESTICHUB_LOG_LEVEL` | `info` | Уровень журнала, например `info` или `debug`. |
| `RESTICHUB_TRUSTED_PROXIES` | нет | Сети обратных прокси в формате CIDR через запятую. Заголовку `X-Forwarded-For` сервер управления доверяет только из этих сетей. См. [Предел частоты регистрации агентов](/restichub/ru/operations/enrollment-rate-limit/). |
| `RESTICHUB_TENANCY_MODE` | `single` | `single` или `multi`. |
| `RESTICHUB_TENANCY_DEFAULT_TENANT` | `default` | Имя организации, которую использует режим `single`. |
| `RESTICHUB_LOG_RETENTION_DAYS` | `30` | Сколько дней сервер управления хранит текст журналов заданий. Наименьшее значение — 1, наибольшее — 36500. См. [Задания](/restichub/ru/concepts/job-lifecycle/). |
| `RESTICHUB_AUDIT_REFUSAL_LIMIT` | `10` | Сколько записей аудита в минуту могут создать отклонённые сообщения одного агента по одной причине. Остальные отказы сервер управления считает и пишет одну сводную запись, когда минута заканчивается или соединение закрывается. Наименьшее значение — 1. |

## Сервер управления: база данных и секреты

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `RESTICHUB_DATABASE_URL` | обязательна | URL PostgreSQL для рабочей учётной записи (runtime). |
| `RESTICHUB_DATABASE_PASSWORD` | нет | Пароль рабочей учётной записи. Не указывайте пароль ещё и в URL. |
| `RESTICHUB_DATABASE_PASSWORD_FILE` | нет | Путь к файлу с этим паролем. Используйте его вместо переменной. |
| `RESTICHUB_DATABASE_MIGRATION_URL` | нет | URL PostgreSQL для учётной записи владельца. Без него сервер управления не применяет миграции. |
| `RESTICHUB_DATABASE_MIGRATION_PASSWORD` | нет | Пароль учётной записи владельца. |
| `RESTICHUB_DATABASE_MIGRATION_PASSWORD_FILE` | нет | Путь к файлу с этим паролем. |
| `RESTICHUB_KEK` | нет | Ключ шифрования ключей (KEK). Он открывает пароли репозиториев и удостоверяющий центр установки. Не рекомендуется: `docker inspect` и окружение процесса показывают значение. Используйте `RESTICHUB_KEK_FILE`. |
| `RESTICHUB_KEK_FILE` | нет | Путь к файлу с KEK. Эталонный набор подключает туда секрет Docker. У файла не должно быть прав для группы и остальных, например `0400` или `0600`. Задайте `RESTICHUB_KEK` или `RESTICHUB_KEK_FILE`, но не обе переменные. |

## Сервер управления: вход

| Переменная | По умолчанию | Единица | Назначение |
|---|---|---|---|
| `RESTICHUB_AUTH_SESSION_IDLE_SECS` | `1800` (30 минут) | секунды | Сеанс заканчивается после такого времени без запросов. |
| `RESTICHUB_AUTH_SESSION_ABSOLUTE_SECS` | `43200` (12 часов) | секунды | Сеанс заканчивается через такое время независимо от использования. |
| `RESTICHUB_AUTH_SIGN_IN_USER_RATE` | `10` | попыток в минуту | Наибольшее число попыток входа для одного имени пользователя. |
| `RESTICHUB_AUTH_SIGN_IN_IP_RATE` | `30` | попыток в минуту | Наибольшее число попыток входа с одного IP-адреса. |
| `RESTICHUB_AUTH_MAX_CONCURRENT_HASHES` | число процессоров | штуки | Наибольшее число одновременных хешей паролей. Каждый хеш занимает около 19 МиБ памяти. |
| `RESTICHUB_SERVER_INSECURE_COOKIES` | `false` | `true` или `false` | Отключает атрибут `Secure` cookie сеанса. Используйте только для локальной разработки по обычному HTTP. |

## Сервер управления: приём агентов

| Переменная | По умолчанию | Единица | Назначение |
|---|---|---|---|
| `RESTICHUB_AGENT_LISTEN` | нет | адрес и порт | Адрес приёма агентов, например `0.0.0.0:8443`. Без него приём агентов и точка регистрации отключены. |
| `RESTICHUB_AGENT_ENDPOINT` | нет | URL | Публичный адрес `https`, по которому подключается агент. Сервер управления сообщает его агенту при регистрации. |
| `RESTICHUB_AGENT_TLS_CERT_FILE` | нет | путь | Сертификат сервера для приёма агентов. Без него сервер использует сертификат из удостоверяющего центра установки. |
| `RESTICHUB_AGENT_TLS_KEY_FILE` | нет | путь | Закрытый ключ этого сертификата. |
| `RESTICHUB_AGENT_MAX_CONNECTIONS` | `2200` | штуки | Наибольшее число открытых соединений для приёма агентов. |
| `RESTICHUB_EVENTS_MAX_STREAMS` | `2000` | штуки | Наибольшее число открытых потоков событий веб-интерфейса на сервере. Одна вкладка браузера держит один поток. |
| `RESTICHUB_AGENT_CERT_LIFETIME_SECS` | `2592000` (30 дней) | секунды | Срок действия сертификата агента. От 600 (10 минут) до 7776000 (90 дней). Агент заменяет сертификат, когда пройдёт две трети срока. См. [Замена сертификата агента](/restichub/ru/operations/certificate-rotation/). |
| `RESTICHUB_REENROLL_TOKEN_MAX_TTL_SECS` | `3600` | секунды | Наибольший срок действия токена, привязанного к хосту. См. [Повторная регистрация хоста](/restichub/ru/guides/enroll-a-host-again/). |
| `RESTICHUB_REPLACE_ONLINE_WINDOW_SECS` | `300` | секунды | Старая запись хоста, которая выходила на связь в этом окне, не заменяется. |

## Сервер управления: очередь

| Переменная | По умолчанию | Единица | Назначение |
|---|---|---|---|
| `RESTICHUB_QUEUE_AGENT_LIMIT` | `2` | штуки | Наибольшее число заданий, которые идут на одном агенте. |
| `RESTICHUB_QUEUE_REPOSITORY_LIMIT` | `4` | штуки | Наибольшее число резервных копий, которые идут в одном репозитории. |
| `RESTICHUB_QUEUE_GLOBAL_LIMIT` | `100` | штуки | Наибольшее число заданий, которые идут в одной организации. |
| `RESTICHUB_QUEUE_LEASE_SECS` | `60` | секунды | Сколько сервер управления ждёт подтверждения задания, прежде чем отправить его снова. Наименьшее значение — 15. |
| `RESTICHUB_QUEUE_LOCK_RETRY_LIMIT` | `5` | штуки | Число ответов о блокировке, после которого задание получает состояние «Попытки исчерпаны». |
| `RESTICHUB_QUEUE_LOCK_RETRY_BASE_SECS` | `30` | секунды | Задержка перед первым повтором при блокировке. С каждым повтором она удваивается. |

Правила очереди описаны на странице [Задания](/restichub/ru/concepts/job-lifecycle/).

## Ограничения времени заданий

| Переменная | Кто читает | По умолчанию | Единица | Назначение |
|---|---|---|---|---|
| `RESTICHUB_JOB_STALL_TIMEOUT_SECS` | сервер управления | `3600` (60 минут) | секунды | Лимит «Остановить, если нет прогресса» для нового профиля. Сервер управления округляет значение вверх до целых минут. Допустимо от 300 до 604800, другие значения игнорируются. |
| `RESTICHUB_JOB_MAX_DURATION_SECS` | сервер управления | `172800` (48 часов) | секунды | Максимальная длительность для нового профиля. Допустимо от 0 до 2592000. 0 — без ограничения. Другие значения игнорируются. |
| `RESTICHUB_JOB_STALL_TIMEOUT_SECS` | агент | 60 минут. 6 часов для `check` и `prune`. | секунды | Тайм-аут простоя задания, у которого он не задан. Значение вне диапазона от 60 до 604800 заменяется ближайшей границей. |
| `RESTICHUB_JOB_HARD_CEILING_SECS` | сервер управления | `2678400` (31 день) | секунды | Время, после которого сервер управления завершает выполняющееся задание с ошибкой при любых ограничениях. Значение меньше 3600 становится равным 3600. |

Существующий профиль сохраняет свои значения. См. [Профили](/restichub/ru/concepts/profiles/#лимиты-заданий) и [Задания](/restichub/ru/concepts/job-lifecycle/#ограничения-по-времени).

| `RESTICHUB_SMTP_USERNAME` | нет | Имя пользователя для SMTP-сервера. |

| `RESTICHUB_SMTP_PASSWORD_FILE` | нет | Путь к файлу с паролем. |
| `RESTICHUB_SMTP_FROM` | нет | Адрес отправителя. Обязателен, если задан хост. |

## Стек Docker Compose

Файл `.env` стека содержит ещё несколько значений. Большинство из них записывает скрипт `init-env.sh`. См. [Установка сервера управления](/restichub/ru/getting-started/install-control-plane/).

| Переменная | Назначение |
|---|---|
| `RESTICHUB_OWNER_PASSWORD`, `RESTICHUB_RUNTIME_PASSWORD` | Пароли учётной записи владельца и рабочей учётной записи базы данных. |
| `RESTICHUB_DOMAIN`, `RESTICHUB_ACME_EMAIL` | Имя хоста сервера управления и адрес электронной почты для его сертификата. |
| `RESTICHUB_IMAGE` | Ссылка на образ сервера управления с дайджестом выпуска. |
| `RESTICHUB_AGENT_PORT` | Опубликованный порт приёма агентов. По умолчанию — 8443. |

## Агент

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `RESTICHUB_JOB_STALL_TIMEOUT_SECS` | см. «Ограничения времени заданий» | Тайм-аут простоя задания, у которого он не задан. |
| `RESTICHUB_LOG_SPOOL_MAX_BYTES` | `67108864` (64 МиБ) | Наибольший объём неподтверждённого журнала заданий, который агент хранит на диске для всех заданий. См. [Задания](/restichub/ru/concepts/job-lifecycle/#журнал-задания). |

Агент также учитывает `HTTPS_PROXY`, `HTTP_PROXY` и `NO_PROXY`. См. [Регистрация агента](/restichub/ru/reference/agent-packages/#прокси-для-скачивания). Других переменных `RESTICHUB_` у агента нет.

## Переменные сборки и тестов

`RESTICHUB_BUILD_VERSION` задаёт ревизию в версии сборки. `RESTICHUB_RELEASE_VERSION` задаёт версию выпуска с суффиксом предварительной версии, например `0.1.0-rc.2`. Сборка сообщает `<версия>+<ревизия>`. CI устанавливает обе переменные при сборке выпуска. Переменные `RESTICHUB_TEST_DATABASE_URL`, `RESTICHUB_TEST_RESTIC`, `RESTICHUB_TEST_DETACHED` и `RESTICHUB_REQUIRE_RESTIC` нужны для тестов проекта. Не задавайте их в рабочей установке.
