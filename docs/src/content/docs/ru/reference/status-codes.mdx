## Отклонённые задания

Если сервер управления не может собрать задание, задание завершается с кодом причины:

| Причина | Значение |
|---|---|
| `compile_failed` | Команды из профиля для этого агента построить нельзя. |
| `agent_facts_invalid` | Сведения об агенте неверны. |
| `agent_capability_missing` | Агент слишком старый для шага. Он не знает поле, которое нужно шагу. |
| `forget_without_tags` | У шага политики хранения нет фильтра по тегам. Сервер управления такой шаг не отправляет. |
| `step_missing` | В профиле больше нет шага этого задания. |
| `agent_revoked` | Агент отозван. |
| `plan_missing`, `plan_changed` | План удалён или перенесён на другой агент. |
| `profile_missing`, `repository_deleted`, `repository_changed` | Объект задания удалён или изменён. |
| `secret_unavailable` | Секрет репозитория нельзя прочитать. |
| `signing_failed` | Сервер управления не смог подписать задание. |

## Отказы при удалении

Если запись мешает удалению, сервер управления отвечает `409 Conflict` с кодом. Перед подтверждением веб-интерфейс запрашивает `GET /api/v1/repositories/{id}/usage`, или `/profiles/{id}/usage`. Ответ имеет ту же форму, что и отказ: в поле `blocked_by` стоит код, а если удаление разрешено, то null.

В теле ошибки кода, который называет записи, есть объект `blockers`. В нём не больше 10 записей, у каждой `kind`, `id` и `name`, и поле `total` с числом всех записей.

| Код | Значение |
|---|---|
| `repository_in_use` | Репозиторий используют профили. Переключите профили на другой репозиторий или удалите их. |
| `repository_has_active_job` | На репозитории выполняется задание. Дождитесь его завершения или отмените его. |
| `profile_in_use` | Профиль используют планы. Переключите планы на другой профиль или удалите их. |
| `secret_in_use` | Секрет используют репозиторий, канал, профиль или шаблон задания. |
| `last_admin` | Пользователь — последний администратор организации. |
| `own_account_protected` | Нельзя удалить, отключить или понизить свою учётную запись. |
| `platform_tenant_protected` | Организацию платформы нельзя приостановить или удалить. |
