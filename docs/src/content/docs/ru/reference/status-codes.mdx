## Отклонённые задания

Если сервер управления не может собрать задание, задание завершается с кодом причины:

| Причина | Значение |
|---|---|
| `compile_failed` | Команды из профиля для этого агента построить нельзя. |
| `agent_facts_invalid` | Сведения об агенте неверны. |
| `agent_capability_missing` | Агент слишком старый для шага. Он не знает поле, которое нужно шагу. |
| `forget_without_tags` | У шага политики хранения нет фильтра по тегам. Сервер управления такой шаг не отправляет. |
| `step_missing` | В профиле больше нет шага этого задания. |
| `agent_revoked` | Агент отозван. |
| `plan_missing`, `plan_changed` | План удалён или перенесён на другой агент. |
| `profile_missing`, `repository_deleted`, `repository_changed` | Объект задания удалён или изменён. |
| `parameter_missing` | У обязательного параметра профиля нет значения. |
| `secret_unavailable` | Секрет репозитория нельзя прочитать. |
| `signing_failed` | Сервер управления не смог подписать задание. |

## Отклонённые расположения репозиториев

В организации одно расположение занимает один репозиторий. Создание или изменение с расположением другого репозитория даёт `409` с кодом `repository_location_taken`. Ответ называет поле расположения и содержит `existing_name`, имя репозитория, который занимает расположение.

| Хранилище | Расположение | Поле |
|---|---|---|
| S3 | Адрес, бакет и префикс | `backend.bucket` |
| REST-сервер | URL | `backend.endpoint` |
| Локальное | Хост и путь | `backend.path` |

Перед сравнением сервер управления приводит запись к одному виду: регистр хоста, порт по умолчанию, завершающий слэш и сегмент `.` в пути. Существующий репозиторий не меняется. При запуске сервер управления пишет для него предупреждение в журнал, а список помечает его как «Общее расположение».

## Отказы по параметрам

Запись, после которой у плана нет значения обязательного параметра, даёт `400` с кодом `parameter_missing` или `parameter_missing_in_plans`. В теле ответа есть поле `parameters` с именами параметров. Для `parameter_missing_in_plans` в теле есть ещё `blockers` со списком планов. Сервер управления ничего не меняет.

| Код | Значение |
|---|---|
| `parameter_missing` | При сохранении плана или в задании нет значения обязательного параметра. |
| `parameter_missing_in_plans` | Сохранение профиля или изменение значений хоста оставляет план без обязательного параметра. |
| `parameter_kind_mismatch` | Тип значения не совпадает с объявлением. Значение неверного типа считается отсутствующим. |
| `parameter_not_declared` | Шаблон или переменная скрипта называет параметр, которого нет в профиле. |
| `parameter_needs_default` | Необязательный параметр без значения по умолчанию стоит в пути или теге. Его значение было бы пустой строкой. |
| `parameter_not_allowed` | Параметр стоит в правиле хранения или в проверке. Один шаг обслуживания выполняет работу для всех хостов, поэтому значения параметра там нет. |
| `parameter_secret_in_template` | Секретный параметр стоит в пути, исключении или теге. Аргументы restic видны в списке процессов. |

## Отказы при удалении

Если запись мешает удалению, сервер управления отвечает `409 Conflict` с кодом. Перед подтверждением веб-интерфейс запрашивает `GET /api/v1/repositories/{id}/usage`, или `/profiles/{id}/usage`. Ответ имеет ту же форму, что и отказ: в поле `blocked_by` стоит код, а если удаление разрешено, то null.

В теле ошибки кода, который называет записи, есть объект `blockers`. В нём не больше 10 записей, у каждой `kind`, `id` и `name`, и поле `total` с числом всех записей.

| Код | Значение |
|---|---|
| `repository_in_use` | В репозиторий пишут планы. Перенесите планы в другой репозиторий или удалите их. |
| `repository_has_active_job` | На репозитории выполняется задание. Дождитесь его завершения или отмените его. |
| `profile_in_use` | Профиль используют планы. Переключите планы на другой профиль или удалите их. |
| `secret_in_use` | Секрет используют репозиторий, канал, профиль, шаблон задания, значение параметра хоста или значение параметра плана. |
| `last_admin` | Пользователь — последний администратор организации. |
| `own_account_protected` | Нельзя удалить, отключить или понизить свою учётную запись. |
| `platform_tenant_protected` | Организацию платформы нельзя приостановить или удалить. |
