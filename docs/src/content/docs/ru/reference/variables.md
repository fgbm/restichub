title: Переменные шаблона

---

Поле профиля может содержать переменную. Сервер управления заменяет переменную на значение для каждого хоста, когда собирает задание. Переменная записывается как `{{имя}}`. Перед `{{` нет пробела, модификаторов нет.

```text
/srv/{{hostname}}/data
/var/backups/{{param.pg_dir}}/{{date:%Y-%m-%d}}
```

Подстановка выполняется один раз. Подставленное значение второй раз не разбирается.

## Переменные хоста

| Переменная | Значение | Пример |
|---|---|---|
| `hostname` | Имя хоста агента. | `db-01.example.com` |
| `os` | Операционная система агента. | `linux`, `windows` или `macos` |
| `agent.name` | Имя агента в ResticHub. | `db-01` |
| `agent.label.<ключ>` | Значение метки агента с ключом `<ключ>`. Метку задаёт регистрация. | `{{agent.label.env}}` даёт `prod` |
| `date` | Дата запуска в формате `%Y-%m-%d`. | `2026-10-14` |
| `date:<формат>` | Дата запуска в вашем формате. | `{{date:%Y%m%d}}` даёт `20261014` |

Метка должна быть у хоста плана. Если у хоста нет метки, сервер управления отклоняет план или задание.

### Формат даты

| Директива | Значение | Пример |
|---|---|---|
| `%Y` | Год, четыре цифры. | `2026` |
| `%m` | Месяц, две цифры. | `10` |
| `%d` | День, две цифры. | `14` |
| `%H` | Час, две цифры, 24-часовой формат. | `09` |
| `%M` | Минута, две цифры. | `42` |
| `%S` | Секунда, две цифры. | `00` |
| `%%` | Знак процента. | `%` |

Любая другая директива — ошибка. Текст без `%` остаётся как есть, поэтому `{{date:%Y-%m}}` даёт `2026-10`.

## Параметры профиля

`{{param.<имя>}}` даёт значение объявленного параметра. Сервер управления выбирает значение в таком порядке: план, хост, значение по умолчанию. См. [Параметры профиля](/restichub/ru/concepts/profile-parameters/).

Параметр типа «Секрет» не подставляется никогда. Командная строка restic видна в списке процессов.

## Где применяется переменная

| Поле | Переменные хоста | Параметры профиля |
|---|---|---|
| Пути, отдельно для каждой системы | да | да |
| Исключения | да | да |
| Файл со списком исключений на хосте | да | да |
| Теги | да | да |
| Правила хранения: теги хранения, теги и пути фильтра | да | нет |
| Правила хранения: срок, хосты фильтра | нет | нет |
| Проверка репозитория: доля чтения данных | нет | нет |

Параметр не подставляется в правила хранения и в проверку, потому что один шаг обслуживания выполняет работу для всех хостов репозитория. Сервер отклоняет параметр с кодом `parameter_not_allowed`.

В поле срока хранения указывают длительность, а в поле доли чтения данных — `N%` или `N/M`. Шаблон в этих полях не проходит проверку формата и получает код `invalid_format`. В поле хостов фильтра нельзя ставить `{`, потому что шаг обслуживания профиля выполняет работу для всех хостов его планов.

Значение в пути, исключении или теге входит в команду restic и в снимок. Его видят все роли, которые видят задания и снимки.

## Список в редакторе профиля

Поля путей, исключений, файла исключений и тегов открывают список, когда вы вводите `{{`. Поля правил хранения и проверки список не открывают. В списке две группы:

- «Параметры профиля» — каждый объявленный параметр с типом и описанием.
- «Переменные хоста» — переменные из таблицы выше, у каждой пример.

Текст после `{{` фильтрует список. В подвале показано число строк. В списке работают такие клавиши:

| Клавиша | Действие |
|---|---|
| `↑`, `↓` | Двигают подсветку. Секрет остаётся серым, стрелки его пропускают. |
| Enter | Вставляет переменную целиком, с закрывающими скобками. |
| Esc | Закрывает список и оставляет текст. |

У секретного параметра в списке указана причина, по которой его нельзя подставить в путь или тег. В поле тегов Enter принадлежит списку, пока список открыт. Второй Enter добавляет чип.

Если имя не объявлено, под полем появляется подсказка «Параметр … не объявлен.» и кнопка «Объявить». Кнопка добавляет строку типа «Текст» с включённым «Обязательный».

## Ошибки

| Ошибка | Причина |
|---|---|
| `unknown variable` | Имени нет в таблицах выше. |
| `agent label … is missing` | Ни один хост планов не задаёт метку. |
| `invalid date format` | В формате есть директива, которой нет в таблице. |
| `unterminated variable` | Нет закрывающих `}}`. |
| `the parameter … has no value` | Ни один источник не даёт значение параметра. |
| `the parameter … is a secret and cannot be expanded` | Секретный параметр стоит в пути, исключении или теге. |
| `the parameter … cannot expand in this field` | Параметр стоит в правиле хранения или в проверке. |
