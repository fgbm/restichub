Верхняя панель показывает организацию, путь к текущей странице, переключатель темы и меню учётной записи. Под верхней панелью вкладки открывают разделы организации. Набор вкладок зависит от вашей роли.

## Списки

Все списки работают одинаково:

- Поле поиска над списком находит запись по имени и по связанным именам.
- Вкладки состояний показывают счётчик для каждой группы, например «Выполняются» или «Не выполнены».
- Фильтры справа сужают список, например по хосту или по репозиторию. Каждый применённый фильтр показывает метку. «Сбросить» убирает все фильтры.
- Меню сортировки меняет порядок списка.
- Длинный список делится на нумерованные страницы. Строка под списком показывает «Показано с 1 по 25 из 146».

## Что запоминает интерфейс

Интерфейс сохраняет ваши настройки отображения в браузере и применяет их при следующем визите. Список запоминает вкладку, фильтры, порядок сортировки и размер страницы. Страница «Восстановление» запоминает репозиторий. Страница записи запоминает, какие разделы свёрнуты, отдельно для каждого вида страниц. Панель команд restic запоминает операционную систему. Ссылка с параметрами всегда открывается со своими параметрами. Кнопка «Сбросить» очищает сохранённые фильтры списка. Интерфейс не запоминает текст поиска, номер страницы, значения полей формы и секреты. Сохранённые настройки действуют только в одном браузере и не переходят в другой браузер. Другой пользователь того же браузера видит только те настройки, которые относятся к нему и к его организации.

## Страницы записей

Выберите имя записи, чтобы открыть её страницу, например страницу задания или профиля. Страница с формой состоит из разделов, которые можно раскрыть и свернуть. Панель справа показывает итог формы. Панель внизу страницы сообщает, есть ли в форме изменения, и содержит «Сохранить». На странице существующей записи кнопка «Сохранить» доступна, только когда есть изменения. Кнопка «Отмена» видна, только когда есть изменения.

## Хосты

Список показывает для каждого хоста последнюю связь, систему и версию агента. «Добавить хост» создаёт одноразовый токен регистрации. См. [Добавление хоста](/restichub/ru/getting-started/add-a-host/).

<Screen name="hosts-list-online" alt="Список хостов с тремя хостами в сети" />

## Репозитории

Список показывает репозитории организации. Выберите имя, чтобы изменить расположение, доступ или обслуживание. См. [Добавление репозитория](/restichub/ru/guides/add-a-repository/).

<Screen name="repositories-list" alt="Список репозиториев" />

## Профили

Профиль задаёт, что копировать, куда и сколько хранить снимки. См. [Профили](/restichub/ru/concepts/profiles/).

<Screen name="profiles-list" alt="Список профилей" />

## Планы

План запускает профиль на хосте по расписанию. См. [Планы](/restichub/ru/concepts/plans/).

<Screen name="plans-list" alt="Список планов" />

## Задания

Список показывает каждый запуск плана и каждую ручную операцию, сначала новые. Выберите имя, чтобы прочитать шаги и журнал задания. См. [Просмотр и отмена заданий](/restichub/ru/guides/jobs/).

<Screen name="jobs-list" alt="Список заданий с вкладками состояний и фильтрами" />

## Восстановление

Выберите репозиторий и снимок. Страница снимка показывает дерево файлов, а «Восстановить…» запускает восстановление. Эту вкладку видят Администратор и Оператор. См. [Восстановление](/restichub/ru/guides/restore/).

<Screen name="restore-snapshot" alt="Страница снимка с деревом файлов" />

## Оповещения

Список показывает открытые и закрытые оповещения. См. [Оповещения и каналы уведомлений](/restichub/ru/guides/alerts/).

<Screen name="alerts-list" alt="Список оповещений с одним открытым оповещением" />

## Аудит

Журнал аудита показывает каждую записанную операцию и её автора. По умолчанию он открывается за последние 30 дней. Поиск находит запись по имени объекта или автора.

<Screen name="audit-log" alt="Журнал аудита с группировкой по дням" />

## Настройки

«Настройки» видит только Администратор. На странице три группы:

- «Доступ»: «Пользователи», «Токены API» и «Секреты».
- «Уведомления»: «Каналы» и «Правила оповещений».
- «Скрипты»: «Шаблоны скриптов» и «Шаблоны заданий».

<Screen name="settings-access" alt="Страница настроек со списком пользователей" />

## Администрирование платформы

Администратор платформы видит ещё «Администрирование платформы» в меню организации на верхней панели. Там находятся «Организации», «Пользователи» и «Аудит» всей установки. См. [Пользователи](/restichub/ru/guides/users/).
