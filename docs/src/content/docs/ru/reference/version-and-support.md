---
title: Версия и поддержка
description: Как узнать версию сервера управления и какие данные отправить в поддержку.
---

Страница «О ResticHub» показывает версию сервера управления, версии протокола и окружение сервера. Отправьте эти данные в поддержку вместе с вопросом. Страницу открывает любой пользователь, который вошёл в систему. Это относится и к установке с одной организацией, и к учётной записи без организации.

## Узнать версию

1. Откройте меню учётной записи в верхней панели.
2. Выберите «О ResticHub».

Пункт меню учётной записи показывает краткую версию под названием. Страница показывает эти данные:

| Данные    | Значение                                                                             |
| --------- | ------------------------------------------------------------------------------------ |
| Версия    | Версия сервера управления вместе с предрелизной частью. Предрелизная сборка показывает метку «Предрелиз». |
| Ревизия   | Коммит сборки. Сборка из исходного кода показывает `dev`.                            |
| Протокол  | Версия протокола между сервером управления и агентами.                              |
| Агенты    | Самая старая версия агента, которую принимает сервер управления, и её старшая версия. Агент другой старшей версии отклоняется. |

## Окружение сервера

Страница показывает окружение сервера (ADR-0055):

| Данные              | Значение                                                                                                        |
| ------------------- | --------------------------------------------------------------------------------------------------------------- |
| Операционная система | Семейство операционной системы процесса, например `linux`.                                                    |
| Дистрибутив         | Дистрибутив процесса, например `Ubuntu 24.04.1 LTS`. Только Linux.                                             |
| Ядро                | Версия работающего ядра. Только Linux.                                                                          |
| Архитектура         | Архитектура процесса, например `x86_64`.                                                                        |
| Контейнер           | «Да», если сервер управления работает в контейнере, и «Нет», если он работает на хосте.                        |
| PostgreSQL          | Версия сервера базы данных, например `16.4`.                                                                    |

Дистрибутив не показывается, если его название содержит необычный символ или очень длинное. Так Debian показывает «Не задано» для дистрибутива, потому что название содержит косую черту.

Данные, которые процесс не сообщает, показывают текст «Не задано». Так ядро и дистрибутив показывают «Не задано» в Windows. Контейнер показывает «Не задано», если процесс не может отличить контейнер от хоста. Версия PostgreSQL показывает «Не задано», если база данных не отвечает на запрос.

## Отправить данные в поддержку

Блок «Данные для поддержки» содержит один текст: версию, ревизию, протокол, диапазон версий агентов и окружение сервера. Нажмите «Копировать». Вставьте текст в обращение в поддержку. Одного текста достаточно для поддержки.

## Данные установки

Администратор платформы видит ещё два данных:

- Организации: «Одна организация» или «Несколько организаций». Это режим установки: одна организация или несколько организаций (ADR-0024). Текст для поддержки содержит режим для всех ролей: `GET /api/v1/instance` сообщает его без входа в систему.
- Версия схемы базы данных: версия последней миграции базы данных. Сравните её с версией в примечаниях к выпуску, если обновление не удалось.

Для остальных ролей этого блока нет.
