## Части системы

| Часть | Назначение |
|---|---|
| Сервер управления | Хранит конфигурацию, создаёт задания по расписанию, отправляет их агентам и показывает результаты. |
| Агент | Работает на каждом хосте: получает подписанные задания, запускает restic и отправляет результаты. |
| Репозиторий | Репозиторий restic. Агент обращается к нему напрямую. |

## Термины

| Термин | Значение |
|---|---|
| Организация | Единица изоляции в одной установке: владеет хостами, репозиториями, планами, профилями, секретами и членством. |
| Профиль | Описание резервного копирования: репозиторий, пути, исключения, срок хранения, хуки. |
| План | Профиль, назначенный на агенты, с расписанием. |
| Задание | Один запуск плана или ручная операция. |
| Шаг | Одна команда в задании, например `backup` или `forget`. |
| Хук | Разрешённая команда, которая запускается до или после restic. |
| Агент обслуживания | Агент, который выполняет `forget`, `prune` и `check` для репозитория. |

## Как выполняется задание

1. Сервер управления определяет по расписанию плана, когда запускать следующее задание.
2. Когда это время наступает, сервер управления ставит задание в очередь.
3. Когда репозиторий свободен, сервер управления подписывает задание и отправляет его агенту.
4. Агент проверяет подпись.
5. Агент выполняет шаги по порядку и отправляет ход выполнения на сервер управления.
6. Агент отправляет результат. Сервер управления показывает его на панели мониторинга.
