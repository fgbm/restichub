Профиль содержит репозиторий, пути, исключения, теги, параметры копирования и ограничения резервной копии (FR-PF-01). Эта страница перечисляет параметры, которые меняют запуск restic.

## Параметры копирования

| Параметр | Действие |
|---|---|
| Снимок файловой системы (VSS) | Передаёт `--use-fs-snapshot`. Только узлы Windows. |
| Не выходить за файловую систему | Передаёт `--one-file-system`. |
| Исключить каталоги кэша | Передаёт `--exclude-caches`. |
| Исключить файлы только в облаке | Передаёт `--exclude-cloud-files`. Только узлы Windows. |
| Ограничение отдачи, ограничение приёма | Передают `--limit-upload` и `--limit-download`. Единица — КиБ в секунду. |

### Файлы только в облаке

Облачный сервис, например OneDrive, может держать на диске заглушку. Содержимое файла остаётся в облаке. Когда restic читает такой файл через VSS, Windows отвечает «Access to the cloud file is denied». Тогда копирование завершается с предупреждениями.

Параметр «Исключить файлы только в облаке» заставляет restic пропускать эти файлы. Компилятор добавляет флаг только для узлов Windows, поэтому один профиль подходит для узлов Windows и Linux. У нового профиля параметр включён. Существующий профиль сохраняет прежнее значение. Параметру нужен restic 0.17 или новее.

## Ограничения

| Параметр | По умолчанию | Значение |
|---|---|---|
| Остановить без прогресса | 60 минут | Агент останавливает шаг, который не продвигается это время. От 5 до 10080. |
| Предельная длительность | нет | Агент останавливает задание по истечении этого времени, как бы оно ни шло. От 1 до 43200. |

О том, как агент измеряет продвижение, читайте в разделе [Задания](../jobs/#ограничения-по-времени).
