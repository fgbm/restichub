Сервер управления говорит хосту, что делать. Хост сохраняет свои ограничения. Эта страница показывает, где проходит граница.

## Сервер управления

- Сервер управления подписывает каждое задание ключом подписи заданий. Подпись покрывает шаги и текст каждого скрипта.
- Сервер управления отправляет пароль репозитория и учётные данные бэкенда вместе с заданием. Они нужны только для этого задания.
- Каждый шаг — команда restic фиксированного типа. Задание не может содержать произвольную команду.

## Агент

- Агент проверяет подпись, адресата, срок действия и журнал повторов. Задание, которое не прошло проверку, не запускается.
- Агент запускает скрипт, только если включён локальный режим доверия. Включить режим может только root или администратор хоста. Задание не может его изменить.
- Если режим выключен, агент отклоняет задание со скриптом. Причина — `server_scripts_disabled`.
- Восстановление пишет только внутрь каталога восстановления хоста.
- Агент не хранит секреты задания.

## Что подпись не останавливает

Подпись защищает задание в сети. Она не останавливает человека, который управляет сервером управления или его базой данных. Такой человек может отправить любой типизированный шаг и любой скрипт на хост с режимом доверия. Меры, которые снижают этот риск, описаны в разделе [Безопасность для администратора](/restichub/ru/operations/security-for-operators/).
