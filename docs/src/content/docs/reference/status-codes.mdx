## Refused jobs

If the control plane cannot build a job, the job fails with a reason code:

| Reason | Meaning |
|---|---|
| `compile_failed` | The profile no longer compiles for the agent. |
| `agent_facts_invalid` | The facts of the agent are not usable. |
| `agent_capability_missing` | The agent is too old for the step. It does not know a field that the step needs. |
| `forget_without_tags` | The retention step has no tag filter. The control plane does not send it. |
| `step_missing` | The profile no longer holds the step of the job. |
| `agent_revoked` | The agent is revoked. |
| `plan_missing`, `plan_changed` | The plan is deleted, or it moved to another agent. |
| `profile_missing`, `repository_deleted`, `repository_changed` | An object of the job is deleted or changed. |
| `secret_unavailable` | A secret of the repository cannot be read. |
| `signing_failed` | The control plane could not sign the job. |

## Refused repository locations

A tenant holds one repository for each location. A create or an update that names a location of another repository gives `409` with the code `repository_location_taken`. The problem names the location field and holds `existing_name`, the name of the repository that holds the location.

| Backend | The location is | The field |
|---|---|---|
| S3 | The endpoint, the bucket and the prefix | `backend.bucket` |
| rest | The URL | `backend.endpoint` |
| Local | The host and the path | `backend.path` |

The control plane folds the spelling before it compares. It ignores the case of the host, the default port, a trailing slash and a `.` segment.

A repository that exists already stays as it is. The control plane logs a warning for it at the start, and the list marks it as a shared location.
