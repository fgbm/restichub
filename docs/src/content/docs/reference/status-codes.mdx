## Refused jobs

If the control plane cannot build a job, the job fails with a reason code:

| Reason | Meaning |
|---|---|
| `compile_failed` | The profile no longer compiles for the agent. |
| `agent_facts_invalid` | The facts of the agent are not usable. |
| `agent_capability_missing` | The agent is too old for the step. It does not know a field that the step needs. |
| `forget_without_tags` | The retention step has no tag filter. The control plane does not send it. |
| `step_missing` | The profile no longer holds the step of the job. |
| `agent_revoked` | The agent is revoked. |
| `plan_missing`, `plan_changed` | The plan is deleted, or it moved to another agent. |
| `profile_missing`, `repository_deleted`, `repository_changed` | An object of the job is deleted or changed. |
| `secret_unavailable` | A secret of the repository cannot be read. |
| `signing_failed` | The control plane could not sign the job. |

## Refused deletes

If a record blocks a delete, the control plane answers `409 Conflict` with a code. The web interface asks `GET /api/v1/repositories/{id}/usage`, or `/profiles/{id}/usage` before it asks you to confirm. The answer has the same shape as the refusal: `blocked_by` holds the code, or null if the delete is allowed.

The problem body of a code that names records has a `blockers` object. It holds at most 10 records, each with `kind`, `id` and `name`, and `total`, the count of all the records.

| Code | Meaning |
|---|---|
| `repository_in_use` | A profile uses the repository. Switch the profiles to another repository, or delete them. |
| `repository_has_active_job` | A job runs on the repository. Wait until it ends, or cancel it. |
| `profile_in_use` | A plan uses the profile. Switch the plans to another profile, or delete them. |
| `secret_in_use` | A repository, a channel, a profile or a job template uses the secret. |
| `last_admin` | The user is the last Admin of the organization. |
| `own_account_protected` | You cannot remove, disable or demote your own account. |
| `platform_tenant_protected` | The platform organization cannot be suspended or deleted. |
