The top bar shows the organization, the path to the current page, the theme switch and your account menu. Below the top bar, the tabs open the areas of the organization. Your role decides which tabs you see.

## Lists

All lists work in the same way:

- The search box above the list finds a record by its name and by the related names.
- The state tabs show a counter for each group, for example "Running" or "Failed".
- The filters on the right side narrow the list, for example by host or by repository. Each applied filter shows a chip. "Reset" removes all filters.
- The sort menu changes the order of the list.
- A long list has numbered pages. The line below the list shows "Showing 1 to 25 of 146".

## What the interface remembers

The interface keeps your view in the browser and shows it again on your next visit. A list keeps the tab, the filters, the sort order and the page size. The Restore page keeps the repository. A record page keeps which sections are closed, for each kind of page. The restic commands panel keeps the operating system. A link with parameters always opens with its own parameters. "Reset" clears the kept filters of a list. The interface does not keep the search text, the page number, the values of a form or any secret. The kept view stays in one browser and does not follow you to another browser. A person who signs in to the same browser sees only the view that belongs to that person and to the organization.

## Record pages

Select the name of a record to open its page, for example the page of a job or a profile. A form page has sections that you can expand and collapse. The panel on the right side shows the result of the form. The bar at the bottom of the page tells if the form has changes and holds "Save". On the page of a record that exists, "Save" is available only when the form has changes. "Cancel" shows only when the form has changes.

## Hosts

The list shows each host with its last contact, system and agent version. "Add host" makes a one-time enrollment token. See [Add a host](/restichub/getting-started/add-a-host/).

<Screen name="hosts-list-online" alt="The list of hosts with three online hosts" />

## Repositories

The list shows the repositories of the organization. Select a name to change the location, the access or the maintenance. See [Add a repository](/restichub/getting-started/add-a-repository/).

<Screen name="repositories-list" alt="The list of repositories" />

## Profiles

A profile tells what to back up, where, and how long to keep the snapshots. See [Profiles](/restichub/concepts/profiles/).

<Screen name="profiles-list" alt="The list of profiles" />

## Plans

A plan runs a profile on a host by a schedule. See [Plans](/restichub/concepts/plans/).

<Screen name="plans-list" alt="The list of plans" />

## Jobs

The list shows each run of a plan and each manual operation, the newest first. Select a name to read the steps and the log of the job. See [Watch and cancel jobs](/restichub/guides/jobs/).

<Screen name="jobs-list" alt="The list of jobs with the state tabs and the filters" />

## Restore

Select a repository and a snapshot. The snapshot page shows the tree of files, and "Restore…" starts a restore. An Admin and an Operator see this tab. See [Restore](/restichub/guides/restore/).

<Screen name="restore-snapshot" alt="The page of a snapshot with the tree of files" />

## Alerts

The list shows the open and the resolved alerts. See [Alerts and notification channels](/restichub/guides/alerts/).

<Screen name="alerts-list" alt="The list of alerts with one open alert" />

## Audit

The audit log shows each recorded operation with its actor. It opens with the last 30 days. Search finds a record by the name of the object or of the actor.

<Screen name="audit-log" alt="The audit log grouped by day" />

## Settings

Only an Admin sees "Settings". The page has three groups:

- "Access": "Users", "API tokens" and "Secrets".
- "Notifications": "Channels" and "Alert rules".
- "Scripts": "Script templates" and "Job templates".

<Screen name="settings-access" alt="The settings page with the list of users" />

## Platform administration

A Platform Admin also sees "Platform administration" in the organization menu of the top bar. It holds "Organizations", "Users" and "Audit" of the whole installation. See [Users](/restichub/guides/users/).
